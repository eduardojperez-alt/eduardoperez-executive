# New Publication — Quick Template

Use this when adding a publication manually.

```text
Title:
Newsletter:
Publication date:
LinkedIn URL:
Cover image:
```

Expected output:

```js
{
  id: "",
  type: "article",
  newsletter: "",
  period: null,
  title: "",
  description: "",
  url: "",
  image: "",
  topics: [],
  sourceTopic: null,
  publishedAt: "",
  sortOrder: 0,
  featured: false
}
```

Approved topic values:

```text
Payments
Financial Services
AI
Customer Experience
Growth
Technology
```
